📊 Global Superstore Sales & Profit Analysis Dashboard

📌 Project Overview

This project focuses on analyzing Global Superstore sales and profit data using Microsoft Power BI. The interactive dashboard provides meaningful insights into sales performance, profitability, product categories, customer segments, and regional performance.

🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- CSV Dataset

📂 Dataset

The project uses the Global Superstore dataset containing sales, profit, order, product, customer, and regional information.

📈 Dashboard Features

- Total Sales: Overall sales performance.
- Total Profit: Total profit generated.
- Total Orders: Number of orders.
- Sales by Category: Category-wise sales analysis.
- Monthly Sales Trend: Monthly sales performance.
- Sales by Region: Regional sales distribution.
- Top 5 Sub-Categories by Profit: Identifies the most profitable sub-categories.
- Sales by Segment: Customer segment-wise sales.
- Sales Target Achievement: Tracks sales against the target.

🎯 Key Objectives

- Analyze sales and profit performance.
- Identify top-performing product categories.
- Understand regional sales distribution.
- Track monthly sales trends.
- Generate meaningful business insights through interactive visualizations.
